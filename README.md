# Hadoop and Apache Spark Data Processing Assignment

## Overview

This project demonstrates basic distributed data processing using **Apache Hadoop MapReduce** and **Apache Spark / PySpark** on a Project Gutenberg dataset.

The project covers:

- Hadoop HDFS setup and basic file operations
- MapReduce WordCount
- Spark DataFrame-based metadata extraction
- TF-IDF and cosine similarity implementation
- Author influence network analysis
- Basic analysis of Gutenberg books
